# Cell transplantation and ER272 treatment promote graft integration and neuronal repair in a human ischemic brain organoid model in vitro

This repository contains 1 file that includes the RNA-seq analysis including day 21 hCOs: 5 CONTROL (DMSO) and 5 ER272 treated samples.

The RNA-seq analysis includes:
-PCA plot

-Batch correction using RUVSeq

-Differential expression analysis of ER272 treated hCOs versus DMSO treated hCOs samples
